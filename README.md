# Campaign Engine

A generic, channel-agnostic **campaign / promotion engine** for retail, written in .NET.

It is designed to be the single source of truth for promotions in a distributed retail landscape
(ERP, store POS, e-commerce platform, mobile app) and to be callable from any language:
.NET, Python, Delphi, Java, Go — anything that can send JSON over HTTP.

> 🚧 Work in progress. See [docs/architecture.md](docs/architecture.md) for the design.
